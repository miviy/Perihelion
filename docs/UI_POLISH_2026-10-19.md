# Toolbar and Minecraft font polish — 2026-10-19

The HUD, Modules and Configs buttons share a 16px height with the search field,
equal widths and 4px gaps. Docked utility tabs keep their 7px top inset across
viewport resizes; small inset drift from older layouts is repaired. Independently
positioned tabs still resize proportionally. The active button uses an accent underline.
The larger button bounds are shared by drawing, hover, clicks and recovery, and the HUD
menu clears the taller button by 4px.

The Minecraft GUI/HUD face renders at native size instead of shrinking its bitmap
to 75 percent. This keeps bitmap rows and stroke widths intact at the default scale.
Minecraft text is consequently larger; metrics, wrapping, toolbar widths and HUD
bounds all use the same native size. The existing resource-pack/Unicode font stays
in use. Other font choices retain their size.

Validation: `check assemble --offline` with the pinned Mixin init script passed:
458 tests (161 core, 297 Forge), zero failures/errors/skips. Java 8 font initialization
requires normal macOS desktop access; the restricted test process aborted, then the
build passed with desktop access. Packaged UI checks passed on Forge at 1440x900
(GUI scale 2) and OptiFine M5 at 854x480. Each passed GUI 345, GUI regressions 88,
TabGUI 91, production HUD 93, render-state 61, unload/rejoin and shutdown cleanup
with zero subscriptions/queued work and `stdoutError=false`. Captures for Minecraft,
Sans and fractional menu scaling were visually inspected. These are local GUI checks;
resource-pack fonts and every display/scale combination are not exhaustively covered.
