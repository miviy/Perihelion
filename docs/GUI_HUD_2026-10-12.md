# GUI and HUD revision

Compact HUD/Configs tabs are independently draggable. Left-click opens their view; right-click HUD exposes Edit/Toggle/Reset, and right-click Configs opens/closes its view. The config window header moves and collapses separately. The HUD editor header moves and right-clicks to collapse its smaller controls. Native settings save these positions on release and preserve them across reopen; resizing recovers controls and keeps default toolbar spacing at fractional scales. Search-disabled panels can use the top of the screen.

The shared font atlas now uses an eight-pixel logical face with its ink aligned to the layout origin, excludes blank padding from height measurements, and uses stable glyph metrics. GUI module text is vertically centered; enabled rows have an accent marker; expanded settings have a stronger section background; ON/OFF badges and separate value alignment distinguish controls. Text retains Unicode fallback, measured clipping, theme choices and ownership cleanup.

Logo and Tab GUI have independent visibility and normalized positions. The nearby-player board adds Distance, clear column headers, alternating rows and explicit local-observation time. The reference-inspired player card groups Tags, Analysis and Hypixel actions, with skin/name/ping and optional cached first-login date. Whitelist reuses the native Friends list; Target highlights the board without changing combat selection. Violations and language remain explicitly unavailable. Existing camera/report/API actions keep their behavior and ownership.
