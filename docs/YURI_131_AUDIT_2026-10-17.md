# Yuri 1.3.1 follow-up audit

The later [second parity check](YURI_131_SECOND_CHECK_2026-10-18.md) supersedes
this artifact's results with two additional repairs. The results below remain
historical evidence for the first follow-up artifact.

Reviewed the native implementation against the unchanged Yuri reference
`1cb86ad94ce1f01aa9b715577163c8ecc47b7def`, focusing on rotations, tick phases,
cooldowns, packet ordering, live setting changes and activation/session cleanup.
Perihelion's menus, HUD and shared lifecycle/control architecture remain native.

## Findings repaired

1. **Back Track could strand inbound packets after a live style change.** Old
   batches use an infinite release deadline. Switching to New/MMC without draining
   that head could block later timed packets indefinitely. A synchronized policy
   transition now retires the old capture state and flushes its FIFO against the
   original live handler before the next batch begins. Closed/overflowed sessions
   cannot restart through setting observers. Changes to a delay within the same
   capture policy retain existing deadlines and FIFO order. This intentionally
   fixes an edge case also present in the donor instead of reproducing its stall.
2. **Hit Select evaluated during player input instead of client tick start.** Yuri
   evaluates before entity/player input. The native listener now runs once at
   `ClientTickEvent.START`; END does not reevaluate it. The transformed probe uses
   real event dispatch for hurt-time and damage-upgrade checks, including the
   START/END boundary, instead of calling its private tick method directly.
3. **Aura's cooldown and own-release window differed from the donor.** A late
   native tick previously preserved phase from the old deadline, shortening the
   next interval and changing Hypixel block/release cadence. Aura now restarts its
   cooldown when due, truncates configured CPS intervals to milliseconds as the
   source does, uses configured CPS for the first delay, then applies the mode's
   125 ms Hypixel / 200 ms Legit interval. Its own Hypixel release no longer adds
   another blocked attack tick. A thread-local packet-identity marker excludes only that own
   release from Aura's local packet gate; foreign block traffic remains gated and
   other packet listeners still observe the release normally. Rotated PRE actions
   continue to require the identical submitted request and immutable aim.

## Rotation and packet coverage

Added a transformed Displace/Aura integration probe covering a first unsent aim,
the preceding C05/C06 look followed by one PRE C02 attack, finishing ownership
through the next walking packet, release back to Aura, refusal to borrow a
stronger owner's aim and disable cleanup. Existing tests continue to exercise
stale rays/targets, canceled/buffered walking, immutable previous rotations,
world retirement and scoped camera/slot restoration.

The Hypixel packet probe checks initial configured delay, a late tick's exact
125 ms reset window, attack/block alternation, release-before-attack order and a
foreign packet remaining blocked even during an own release, including foreign dig
traffic. Recursive sends inside raw callbacks remain prohibited by the existing
native dispatch contract. The Hypixel checks use serialized
localhost TCP because integrated-server channels intentionally skip multiplayer
raw packet hooks. Back Track changes
are tested through real local TCP codecs in both directions, alongside its
existing target-change/velocity flush and outbound-buffer overlap cases. The
strict global packet and Forge/core tick ledgers account exactly for measured TCP
traffic and intentionally injected phase events; their equality checks remain.

The source pass also checked frame-based Aim Assist, projectile solver/staging,
Scaffold post-movement planning, Clutch action windows, Inv Move batching and
release countdowns, native queue bounds and handler/generation checks. The pinned
module inventory still accounts for 102 donor definitions: 77 native mappings,
22 presentation exclusions and three previously deferred features (Insults, Skin
Changer and Keybind Info).
