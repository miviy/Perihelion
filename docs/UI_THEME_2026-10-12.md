# Shared UI theme and fonts — 2026-10-12

Modules, Configs, the HUD editor and their navigation controls now use the same native charcoal panels, blue gradient headers, compact flat buttons, spacing and selected font. The supplied Adjust GUI screenshots guide the compact floating-column layout; the existing lavender/salmon HUD accent remains configurable.

## User controls

Open **Client → ClickGUI → Font** and choose:

- **Current**: the existing smooth Sans face and default.
- **Minecraft**: the native game/resource-pack font, including its formatting and shadow behavior.
- **Monospace**: the existing logical JRE monospace face, now shared by all UI and HUD text.

The setting applies to Modules, Configs, text entry, editor chrome, previews and the in-game HUD. Existing `SANS`, `MINECRAFT` and `MONO` config values remain valid; legacy Serif remains available. No font download or new dependency is needed. The JRE resolves the exact Sans/Monospace family on each platform, and unsupported custom-atlas glyphs use native Minecraft glyphs individually.

The Configs view keeps the existing preset save/load/update/delete and file/folder actions in a compact two-column pane. Confirmations, autosave, asynchronous operations and error/status messages remain in the native config workflow. The HUD editor uses the same compact buttons and Elements list; it retains normalized saved positions, drag/hide/reset and return-to-parent behavior. Its Elements popup has a stronger background so preview text does not compete with the controls.

Default module columns wrap into bounded rows so a long body cannot cover another category header. Scrolling remains local to the hovered panel; manually dragged panels remain freely movable. Chat text is suppressed while these custom menus are open, with chat history preserved. Opening `T` still shows chat and the interactive HUD/player board.

## Typography and ownership

Labels use measured ellipses instead of horizontal font compression. Font-specific measurements size player names and table columns. Text entry retains vanilla input/selection/paste state while rendering its text, selection and blinking caret in the selected face, at the existing row size. Glyph boundaries and caret movement avoid splitting Unicode surrogate pairs; fractional scale coordinates snap to framebuffer pixels.

`GuiTheme` shares existing ClickGUI preferences and rendering primitives. Font atlases remain lazily created, screen/HUD owned, and closed through native cleanup. Changing the font invalidates widths and cancels a drag based on old geometry. No donor event bus, module manager, config service, global architecture or assets were imported. References and revisions are recorded in [DONORS.md](DONORS.md).
