# Chat HUD and player board interaction

The original `hide-screens` predicate included `GuiChat`, so pressing T hid every
production HUD element. The dedicated editor could drag panels, but normal chat
had no HUD pointer route. The player table had no detail/context menu.

## Changes

- Chat draws the enabled HUD once through Forge's GUI Post drawing event, above
  the chat screen. Other menus retain `hide-screens`; F1 and the F3 preference
  remain respected. Empty enabled player boards remain available in chat.
- Native `GuiChat` initialization/close hooks start and retire an activation-owned
  chat session. The existing Forge adapter forwards pointer and Escape events into
  the normal client-thread module bus, avoiding another event manager.
- Left-drag moves a visible HUD element. Its transient coordinates change during
  rendering; normalized settings commit on release or ordinary chat closure.
  Resize, HUD deactivation and world loss cancel transient state. Layout reset
  also cancels a drag so a later close cannot overwrite the reset.
- The chat input line remains available, even under a saved HUD position. Pointer
  events outside HUD hit boxes and normal typing/scrolling fall through to vanilla.
  Escape closes a popup first. Right-click in chat does not hide HUD elements;
  the separate editor's existing right-click-to-hide behavior remains available.
- Right-clicking a player row opens actions for that player's UUID: Spectate,
  Report, Pin/Unpin, Hypixel Stats and Player Details. Columns are configured in
  Render → HUD's typed multi-select setting. Small popups scroll above chat input.
- Spectate uses the existing native Freecam module, starts three blocks behind a
  live target, suppresses body input/interaction, and clamps flight around that
  target. Stop, target loss and world changes restore the prior camera. A targeted
  session does not reopen as ordinary Freecam in the next world.
- Report checks the current Hypixel hostname and a live validated plain username,
  then invokes `/report username` to open Hypixel's own selection GUI. It selects
  no reason and submits no report. Local fixtures cannot use this server action.
- Pins are bounded to 64 UUIDs per HUD activation, apply before the row limit, and
  preserve range/loaded-player eligibility. They retire on HUD/world cleanup.
- Explicit stats requests use official `https://api.hypixel.net/v2/player?uuid=...`
  with an `API-Key` header. A HUD setting contains a local key-file path; key bytes
  are neither copied into presets nor logged. One daemon worker, no request backlog,
  five-second timeouts, a 2 MiB body limit, no redirects, five-minute success cache,
  ten-second error cache and server rate-limit backoff bound the operation. Late
  callbacks use native activation/world ownership plus credential-revision guards.
  The selected Bed Wars/SkyWars totals fill the stats card and cached table columns;
  missing numeric fields stay `--`.
- Native player details retain health, team, distance, ping, armor, held item and
  local observation timestamps. Rows/cards use bounded snapshots and UUID identity.
- Keyboard/mouse events emitted after a GUI closes remain blocked GUI input;
  Enter/Escape or a closing-menu click cannot activate a gameplay binding.
- Sampling stays at five Hz and row count remains bounded. Observation timestamps
  retain at most 256 UUIDs, retire with the HUD, and store no entity references.
  Rendering reuses the HUD font and GL scopes. It never starts requests or scans
  for statistics; the explicit lookup worker is owned by the active HUD.

## References and evidence

Arsenic `d6f3a3d40a6d3f14826a42002abf343c61c46ecb`
`src/main/java/arsenic/module/impl/visual/HUD.java` was read for chat visibility and
editor offsets. The Adjust reference `Screenshot 2026-09-15 at 11.11.35 AM.png`
(actual filename contains a narrow no-break space) shows the extended player
board. The user's request defines the player actions and GUI column choices; no exact
Adjust popup implementation was available or claimed.

Forge 1.8.9 GUI event signatures and Minecraft chat initialization/close methods
were checked against the installed/mapped runtime and local read-only sources.
Unit tests cover drag offset/clamp/cancellation, persistent immutable column,
key-path/game settings, API parsing/UUID rejection, bounded reads, credential
headers/redirect refusal, HTTP errors, rate backoff, deduplication, cache expiry,
cache capacity, worker cleanup and retired replies. The native fixture opens actual transformed `GuiChat`, posts Forge's
drawing event, checks GL restoration, drags/saves, opens menus, preserves draft
text, cancels resize/reset/retired drags, and checks closing-GUI input suppression.
Action fixtures pin before limiting rows, start/stop a real detached camera without
moving the body, verify owned input suppression and target/world cleanup, reject
reports in the local world, and render known API fixture values without contacting
Hypixel. A live authenticated Hypixel stats lookup/report GUI has not been tested
because no API key or authenticated Hypixel session was supplied. Local/integrated
world proof does not establish remote server behavior or anti-cheat acceptance.

External contracts were verified against the [official API](https://api.hypixel.net/)
and [Hypixel reporting support article](https://support.hypixel.net/hc/en-us/articles/360019646359-How-to-Report-Rule-Breakers-on-Hypixel).

The final build passed 263 unit tests and 83 chat HUD checks on both Forge and
OptiFine M5. Forge recorded an existing JVM shutdown stdout race; its independent
teardown report confirms cleared hooks, zero listeners and zero queued tasks.
The final build fingerprint, exact checks, captures, limits and runtime notes are in `HUD_CHAT_VERIFICATION_2026-10-12.json`.
