# GUI text customization

Open **Client → ClickGUI** and expand its settings. New controls are Section text, Selected text, Selection highlight (RGBA/alpha), Helper text, Text weight (Regular/Bold), and Bold sections. All update immediately and persist through the existing working config and presets. Existing body-text and enabled-module colors remain independent.

Section colors affect category/window headings and config section labels. Selected colors affect active tabs, presets, expanded modules, setting choices, ON badges, editor element selections and text selection. Selection fill also drives hover shading; helper colors affect bindings and muted labels. Actual bold JRE/native glyphs have matching measurements and Unicode fallback; text entry/caret/clipping use the chosen weight at the same row size. A separate heading face allows bold sections with regular body text. Utility buttons widen only enough to fit the chosen text, while default anchors stay apart through font/weight changes and resize. Font and weight caches are bounded and release their textures through the existing GUI owner. In-game HUD keeps its own colors and regular weight.

**273 unit tests pass** (core 156, Forge 117, no failures/errors/skips), including saved appearance values and independent original colors. Native UI checks and captures are recorded in [the verification JSON](GUI_TEXT_VERIFICATION_2026-10-12.json). The typography fixture checks three fonts at 1/1.05, custom colors/alpha, true bold metrics, Unicode, independent heading weight, caption fit, texture cleanup and no GL error. These are local UI/integrated-world checks.

The exact tested JAR is `forge/build/verified/gui-text-20261012/Perihelion-0.1.0.jar`. The verified pre-edit archive holds 20 files in `.backups/before-gui-text-20261012-183737`. `python3 scripts/restore-gui-text.py` verifies the 13-file rollback without changes; explicit `--apply` refuses later edits and archives current affected files before restoring the previous GUI. Generated JARs/captures remain available; rebuild after restoration.
